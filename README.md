# thirdsem

Minimalist, responsive coursework and practical lab records portal for 3rd semester (MTU).

## subjects

- **discrete**: assignments (separate notebook)
- **dld**: assignments (due 23 nov 2026) & practical lab records (exp 3 & 4)
- **ppl**: assignments (print & submit) & practical lab records (17 experiments, handwritten code + print outputs)
- **dev-tools**: assignments (latex resume & ieee paper) & practical lab records (exp 1-5 print, exp 6-7 handwritten code + print outputs)
- **dsa**: assignments (a4 sheet) & practical lab records (12 experiments, handwritten code + print outputs)
- **feedback-control-systems**: matlab onramp course (mathworks) / certificate portal (mtucert.netlify.app)

## features

- ascii directory tree navigation (`./`)
- embedded pdf viewers with fallback download links
- dark / light theme toggle (persisted in `localStorage`)
- offline access via lightweight service worker (`sw.js`)
- netlify ready (`netlify.toml` & `_redirects`)
